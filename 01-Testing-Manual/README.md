# Testing Manual

## Proyecto: DemoQA – Practice Form

### Descripción
Proyecto de práctica de testing manual sobre un formulario web.

### Objetivo
Evaluar el funcionamiento del formulario, verificar sus validaciones y documentar los resultados de las pruebas.

### Alcance
- Validación de campos obligatorios.
- Ingreso de datos.
- Envío del formulario.
- Comportamiento ante campos incompletos.

### Herramientas
- DemoQA
- Google Chrome
- GitHub
